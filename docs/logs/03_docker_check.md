# 03. Docker 설치·점검 로그

`docker --version`, `docker version`, `docker info`로 설치와 데몬 동작을 확인했다. 데몬이 떠 있으면 `docker info`에 `Server Version`이 나오고, 꺼져 있으면 `Server` 부분 없이 연결 오류가 난다.

- 실행 위치: Windows 11 Pro 노트북, Git Bash (MSYS), Docker Desktop 4.97.0 + WSL2, 기록일 2026-11-02
- 호스트 PC 이름·계정 외 민감정보는 없다 (토큰 등은 `docker login`을 하지 않았으므로 없음).
